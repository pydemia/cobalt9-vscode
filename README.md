# Cobalt9 Theme

A theme by pydemia that keeps the original Cobalt9 colors. A few existing
colors distinguish declarations from references and calls.

## Screenshots

![Cobalt9 in VS Code with Python syntax](images/sample_python.png)

![Cobalt9 in VS Code with Java syntax](images/sample_java.png)

| Role | Color |
| --- | --- |
| Background | `#072539` |
| Text | `#FFFFFF` |
| Comments | `#0088FF` |
| Statements and control keywords | `#FF9D00` |
| Storage and declaration modifiers | `#FF9D00` |
| Class declarations | `#D7BA7D` |
| Type references | `#FFDD00` |
| Function declarations | `#F92672` |
| Function calls | `#FFC600` |
| Built-in functions | `#FF9D00` |
| Variables | `#FB94FF` |
| Parameters | `#F4ABA4` |
| Properties | `#FFDBC7` |
| Strings | `#3AD900` |
| Numbers | `#FB71A3` |
| Built-in constants | `#FF628C` |
| Operators | `#F8F8F8` |
